## `> selected_builds`

A selection of builds, prototypes, and technical experiments:

- **[ZenSec](https://github.com/githubuser2777/ZenSec)** — A file encryption/decryption CLI exploring stream-based AES-256-GCM chunk authentication and keyfile workflows.  
  `Go` `crypto/cipher` `AES-256-GCM` `CLI`

- **[password-manager-cli](https://github.com/githubuser2777/password-manager-cli)** — A local-first password manager exploring local vault encryption with Argon2id + AES-256-GCM and an interactive TUI.  
  `Go` `Argon2id` `AES-256-GCM` `Bubble Tea` `TUI`

- **[ASCII_Zen](https://github.com/githubuser2777/ASCII_Zen)** — A hybrid terminal video player that decodes video frames into real-time ASCII art with standalone executable packaging.  
  `Go` `Python` `OpenCV` `NumPy` `Bubble Tea`

- **[ZenYT](https://github.com/githubuser2777/ZenYT)** — A lightweight desktop utility wrapping `yt-dlp` via Tauri IPC and native webview rendering.  
  `Rust` `Tauri v2` `React` `yt-dlp` `Vite`

- **[ZenFlashCard](https://github.com/githubuser2777/ZenFlashCard)** — A distraction-free flashcard learning application implementing the SuperMemo SM-2 spaced repetition algorithm.  
  `Flutter` `Dart` `SQLite` `SM-2 Algorithm`
